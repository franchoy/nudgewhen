## 2. Purpose

This record covers two documentation-only Build attempts concerning the v0.1.5
Phase-1 reminder-time architecture.

Attempt 1 recorded the maintainer's formal acceptance of the v0.1.5 Phase-1
reminder-time architecture and reconciled the completed native nudge-land
transaction with the existing experiment evidence.

Attempt 2 is the corrective attempt. It corrects the documentation and
experiment-evidence findings raised by the independent review of attempt 1:
the architecture document's residual pre-acceptance wording, one unsupported
factual claim about the machine-readable release contract, an unsupported
outcome label in this record, and missing required experiment fields.

Neither attempt performs Phase 1 lifecycle-status synchronization. That work
belongs to the separately authorized Phase 1C-B step and has not occurred.
Neither attempt implements any reminder-time functionality.

architecture published in `8f811b61328ff24fb6b8db1589316a81b30450bb`,
