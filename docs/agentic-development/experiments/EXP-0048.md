# EXP-0048 — v0.1.3 Integration & Device Validation

This document is the cumulative Phase 5 evidence record for the active
`v0.1.3` release. It is authored from the frozen Phase 5 evidence base
inherited from the original Phase 5-E1 candidate and from the Phase 5
implementation results already landed on `release/v0.1.3`. It is the
authoritative Phase 5 evidence anchor for the Phase 5 closure-
synchronization candidate.

The proven provenance labels used throughout this document are:

- **DIRECT OBSERVATION** — the agent directly observed a fact in the
  current session.
- **RETAINED DIRECT EVIDENCE** — the fact is preserved in a tracked
  repository artifact directly observed by the agent in the current
  session.
- **MAINTAINER-SUPPLIED OBSERVATION** — the fact was observed by the
  maintainer and communicated to the agent in the current session;
  the agent did not directly observe it.
- **MAINTAINER-SUPPLIED DECISION** — the maintainer issued an explicit
  decision that directed the agent's actions in the current session;
  the agent did not directly observe the underlying fact.
- **INFERENCE** — the fact is a strongly-supported conclusion drawn from
  observed evidence; it is not a direct observation.

Provenance classes are preserved separately. A `MAINTAINER-SUPPLIED
OBSERVATION` is not promoted to `DIRECT OBSERVATION`. `INFERENCE` is not
promoted to `DIRECT OBSERVATION` or `RETAINED DIRECT EVIDENCE`.

Historical Phase 5 failures are recorded exactly with their original
labels. Accepted recoveries are recorded separately and are not merged
into the historical failure labels.
