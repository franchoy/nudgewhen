Live-repository denial probes whose accidental allow would itself perform a consequential action are NOT recommended, including:

If exact runtime proof of those dangerous forms is later required, use a separately authorized disposable/sandbox repository or another mechanism where an unexpected allow cannot alter the real working repository.
