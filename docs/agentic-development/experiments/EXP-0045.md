## 3. Frozen Phase 1 contract implemented by Phase 2

The frozen Phase 1 contract that Phase 2 implemented is the accepted Phase 1 architecture contract at `docs/releases/v0.1.3/editing-architecture.md` (frozen SHA-256 `71a8c56e3515a17ebfebd4bde42be90991caab7afeb8528ca4173eec3a0630c5`, architecture commit `9004b0f90f60d2d5c8b1ac4828d0a4521316ae5a`). The implemented frozen behavior set is:

- domain API: `edit(id: String, text: String): Boolean`;
- the Boolean means the edit request was accepted; it does not mean persisted text changed;
- exact-id lookup before normalization;
- a missing id returns `false` and does not save;
- the controller owns `text.trim()` normalization;
- a normalized-empty edit returns `false` and does not save;
- a normalized-identical edit returns `true` and does not save;
- a changed valid edit changes only the target text and returns `true`;
- the target id, the target index, the neighbor order, and the complete candidate list ordering are preserved;
- the complete candidate list is saved exactly once;
- controller state is published only after a successful save;
- save failure propagates and preserves the previous controller state;
- `edit` never invokes `idGenerator`;
- Unicode text is supported.
